==============================================================
 LOJA — LANDING PAGE + CHECKOUT TRANSPARENTE PIX (MERCADO PAGO)
==============================================================

O QUE MUDOU NESTA VERSÃO
--------------------------------------------------------------
1. FRONT-END: Materialize CSS foi removido e substituído por Tailwind CSS v4
   (visual escuro, moderno e elegante). O CSS compilado fica em
   public/css/app.css e a fonte de estilos é src/input.css.

2. CHECKOUT: o Checkout Pro (redirecionamento) foi substituído pelo
   CHECKOUT TRANSPARENTE com UM único método de pagamento: PIX.
   O cliente recebe na própria página o QR Code + o código "copia e cola".
   Cartão, boleto e saldo Mercado Pago foram removidos.

3. ENTREGA AUTOMÁTICA: quando o pagamento é APROVADO o servidor envia
   automaticamente um e-mail com o botão/link de DOWNLOAD do script.
   O envio é idempotente (não duplica) e pode ser reenviado pelo painel.

4. PAINEL ADMIN (/dash): reformulado (sidebar, cards, gráfico, abas,
   tabelas com detalhes) e com uma nova seção "Link de download",
   onde você define o link que vai no e-mail.

5. BANCO: novas colunas/tabelas (link_download, email_enviado,
   valor_total, reembolsos). O servidor aplica sozinho na inicialização,
   mas você também pode rodar o SQL manualmente (veja abaixo).


COMO RODAR
--------------------------------------------------------------
1) npm install

2) Copie .env.example para .env e preencha:
     ACCESS_TOKEN        -> Mercado Pago (painel do desenvolvedor)
     DB_*                -> seu banco MySQL/MariaDB
     API_KEY             -> Mailgun (envio dos e-mails)
     MAILGUN_DOMAIN      -> domínio remetente no Mailgun
     SECRET              -> segredo da sessão
     SITE_URL            -> URL pública HTTPS do site (para o webhook)
     DOWNLOAD_LINK       -> link padrão de download (fallback do banco)

3) Banco de dados:
     - importe banco_de_dados_aqui/backup_tabelas.sql (se for um banco novo)
     - rode a migração:
       mysql -u USUARIO -p NOME_DO_BANCO < banco_de_dados_aqui/migracoes/001_pix_transparente_e_link_download.sql
       (o servidor também aplica essas alterações automaticamente)

4) CSS (só é necessário se você editar o visual):
     npm run dev:css     -> recompila o Tailwind ao salvar
     npm run build:css   -> gera o public/css/app.css minificado
   O app.css já vai commitado, então em produção basta `npm start`.

5) Subir o servidor:
     npm start           (ou `npm run dev` com nodemon)


MODO DEMONSTRAÇÃO (sem banco e sem credenciais)
--------------------------------------------------------------
   DB_MOCK=true MP_MOCK=true npm start

 - DB_MOCK=true : usa um banco em memória com dados fictícios
 - MP_MOCK=true : simula o Mercado Pago (QR Code fictício que é
                  "aprovado" depois de ~15 segundos)
Útil para ver o layout e testar o fluxo do Pix. NUNCA use em produção.


WEBHOOK DO MERCADO PAGO (importante!)
--------------------------------------------------------------
O aviso de pagamento aprovado chega por webhook. Sem ele o sistema ainda
funciona (a página fica consultando o status a cada 4s), mas o e-mail
pode atrasar se o cliente fechar a página.

1. Acesse https://www.mercadopago.com.br/developers/panel/applications
2. Abra a sua aplicação -> Webhooks
3. Em "Pagamentos" informe:  https://SEU-DOMINIO/webhook
4. Salve. O SITE_URL do .env precisa ser o mesmo domínio (HTTPS).


FLUXO DO PAGAMENTO
--------------------------------------------------------------
1. O cliente preenche nome, e-mail e CPF na landing page.
2. POST /pagamento/pix cria o pagamento no Mercado Pago e devolve
   qr_code (copia e cola) + qr_code_base64 (imagem) + expiração.
3. A página mostra o QR Code e consulta GET /pagamento/status/:pedidoId
   a cada 4 segundos.
4. O Mercado Pago chama POST /webhook quando o status muda.
5. Status "approved" (uma única vez) -> e-mail com o link de download.

ROTAS
--------------------------------------------------------------
GET  /                          landing page
POST /pagamento/pix             cria o pagamento Pix (QR + copia e cola)
GET  /pagamento/status/:id      consulta o status do pagamento
POST /webhook                   notificação do Mercado Pago
GET  /success /pending /fail    páginas de retorno
GET  /login  POST /loginuser    autenticação do admin
GET  /logout                    sair
GET  /dash                      painel administrativo
POST /painel/link-download      salva o link de download do e-mail
POST /painel/reenviar-download  reenvia o e-mail com o link
POST /validateupload            atualiza produto (preços/descrição/imagens)
POST /enviar-email-rc           cobra pagamento pendente
POST /enviar-email-rv           recupera venda recusada
POST /enviar-rastreio           envia código de rastreio (entrega física)
POST /reembolsauser             cliente solicita reembolso
POST /refund                    estorna o pagamento no Mercado Pago
GET  /suporte  /suporte/reembolso
GET  /health                    healthcheck
